# NEXUS SECURITY AI

منصة ويب مستقلة للتوعية والتحليل الأمني الدفاعي.

## المزايا
- لوحة تحكم بمؤشرات تجريبية.
- مساعد محلي بردود إرشادية.
- محلل سجلات يعمل داخل المتصفح.
- سجل للأصول والأجهزة.
- قائمة تحقق لتقييم ضوابط الحماية.
- إنشاء وتنزيل تقرير نصي.

## النشر على Vercel
استورد المستودع من GitHub في Vercel. اختر Framework Preset: Other، واترك Build Command فارغاً، وعيّن Output Directory إلى `.` إذا طلب منك ذلك. لا يحتاج الإصدار الحالي إلى Python أو قاعدة بيانات أو متغيرات بيئة.

## ملاحظات
هذه نسخة Frontend تجريبية ولا تتصل بنموذج ذكاء اصطناعي أو Backend. تحليل السجلات قائم على كلمات مفتاحية فقط ولا يؤكد وجود حادث. استخدمها فقط مع الأنظمة التي تملكها أو لديك تصريح واضح بإدارتها. لا تحتوي على وظائف استغلال ثغرات أو مهاجمة أنظمة.
