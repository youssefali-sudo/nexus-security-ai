منصة ويب مستقلة للتوعية والتحليل الأمني الدفاعي، بهوية بصرية خاصة بـ NEXUS SECURITY AI.

## المزايا الحالية
- لوحة تحكم بمؤشرات توضيحية.
- مساعد محلي لشرح مفاهيم الأمن السيبراني الدفاعي.
- محلل سجلات محلي قائم على كلمات مفتاحية.
- سجل للأصول والأجهزة التي تملكها أو تديرها.
- قائمة تحقق لضوابط الحماية الأساسية.
- إنشاء وتنزيل تقرير نصي.

## النشر على Vercel
استورد المستودع من GitHub في Vercel. اختر **Framework Preset: Other**، واترك **Build Command** فارغاً، وعيّن **Output Directory** إلى `.` إذا طُلب منك ذلك. الإصدار الحالي واجهة ثابتة ولا يحتاج إلى Python أو قاعدة بيانات أو متغيرات بيئة.

## خارطة التطوير الدفاعية
المراحل التالية المقترحة: تحسين لوحة الأصول، إضافة استيراد سجلات بصيغ شائعة مع إخفاء البيانات الحساسة، تقارير قابلة للطباعة، وسجل تدقيق للتغييرات. أي تكامل خادمي مستقبلي يجب أن يظل دفاعياً ومحدوداً بالأنظمة التي يملك المستخدم صلاحية إدارتها.

## ملاحظات مهمة
هذه نسخة Frontend تجريبية ولا تتصل حالياً بنموذج ذكاء اصطناعي أو Backend. تحليل السجلات قائم على كلمات مفتاحية ولا يؤكد وجود حادث أمني. لا تُدخل كلمات مرور أو مفاتيح API أو بيانات شخصية. استخدم المشروع فقط لإدارة ومراجعة أنظمتك المصرح بها.
